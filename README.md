# 芭爪娱｜视频拍摄剪辑实操题

## 题目

请围绕芭爪娱产品完成以下三项视频实操：

### 1. 盲盒开箱视频

快速拍摄并剪辑一条盲盒开箱视频，展示拆封过程、产品细节和开箱结果。

### 2. 创意短视频

从以下两个参考视频中任选一个创意方向，完成一条芭爪娱产品创意视频：

- [参考视频 1](https://www.xiaohongshu.com/discovery/item/688b3dc3000000002302adbf)
- [参考视频 2](https://www.xiaohongshu.com/discovery/item/66e55adf0000000026032b8f)

不要求与参考视频画面完全一致，可以借鉴其中的创意形式、镜头语言、节奏或单个创意点，并按照自己的内容重新设计。

### 3. AI 视频

使用公司提供的 AI 视频生成工具，围绕芭爪娱产品制作一条 AI 视频。

## 统一要求

- 视频尺寸：竖屏 9:16；
- 视频时长：单条 20 秒以内；
- 视频内容：需展示芭爪娱产品；
- BGM：自行选择，并与画面节奏匹配；
- 输出格式：MP4；
- 分辨率：1080×1920。

## 提交内容

请提交 3 条视频成片：

1. 盲盒开箱视频；
2. 创意短视频；
3. AI 视频。

素材包包含 20 个 SKU，每个 SKU 配 3 张不同图片，共 60 张图片。
